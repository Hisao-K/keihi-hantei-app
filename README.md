# 経費判定君（アプリの画面）

Kamo's BASE の経費記録アプリ「経費判定君」の画面です。スマホのホーム画面に置いて使います。

- このリポジトリにあるのは画面（HTML・JavaScript・CSS・アイコン）だけです。台帳、領収書の写真、APIキー、サーバー側のコードは入っていません。
- 台帳と写真は、会社の Google Workspace のドライブに保存されます。この画面を置いているサイトには届きません。
- 使えるのは、管理者が登録した会社の Google アカウントでログインした人だけです。
- 判定は入力した内容だけを見たセルフチェックです。税務代理・税務相談ではありません。
